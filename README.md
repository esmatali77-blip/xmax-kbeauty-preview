# X MAX K-BEAUTY — design preview

Live preview: https://esmatali77-blip.github.io/xmax-kbeauty-preview/

This repository holds a **design preview** of the X MAX K-BEAUTY storefront (English and Arabic, right-to-left) for review.

- All products, prices and policies are **demo placeholders**. Nothing can be bought here.
- Images are **editorial illustrations of unbranded products**, not product photography.
- The preview is **not connected to any Shopify store** and contains no keys, tokens or customer data.
- Search engines are asked not to index it (`noindex`).

This repository contains only the built site (`index.html` and `assets/`) served by GitHub Pages, plus `shopify-media/`: unbranded 2048 × 2048 collection images used by the Shopify store.

Pages use hash routes, for example `#/collections/skincare`, `#/products/demo-pdrn-collagen-serum`, `#/cart`. Switch language with the "العربية / English" button in the header.
